# 新人上手指南

## 适用对象

本文档面向首次参与 `sancheng365` 项目的开发、测试、产品、运维和协作人员。

## 第一天：了解项目背景

建议完成以下事项：

1. 阅读 `README.md`，了解项目当前状态和文档入口。
2. 阅读 `docs/architecture.md`，了解计划中的系统架构和待确认问题。
3. 向负责人确认业务目标、当前里程碑和近期优先级。
4. 确认团队协作方式，包括需求管理、代码评审、发布节奏和沟通渠道。

## 第一周：建立开发上下文

当业务代码落地后，建议按以下顺序熟悉项目：

1. 跑通本地开发环境。
2. 阅读项目配置和启动入口。
3. 梳理核心路由、页面或接口。
4. 阅读核心业务模块和数据模型。
5. 跑通测试和静态检查。
6. 选择一个低风险任务完成首次提交。

## 推荐学习路径

- **业务优先**：先理解用户、场景、流程和核心术语，再深入代码实现。
- **入口优先**：从启动脚本、路由入口、API 入口或主页面开始阅读。
- **数据优先**：尽早理解核心实体、字段含义和实体关系。
- **测试辅助**：通过测试用例理解预期行为和边界条件。
- **小步提交**：第一次贡献尽量选择文档、测试或低风险修复。

## 本地环境准备清单

技术栈确定后，请在此补充：

- 操作系统要求。
- 语言和运行时版本。
- 包管理器版本。
- 数据库和缓存依赖。
- 必要的本地工具。
- 依赖安装命令。
- 本地启动命令。
- 测试命令。

1. 当前目标是什么。
