## 环境变量

环境变量示例维护在 `.env.example`。开发者应复制该文件为本地 `.env`，并按实际环境填写配置值。

```bash
cp .env.example .env
```

请勿将真实密钥、生产数据库连接串或第三方服务凭证提交到 Git 仓库。
